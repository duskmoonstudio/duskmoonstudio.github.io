About the studio

Short: Dusk Moon Studio makes small, calm games you play with one touch.

Long: Dusk Moon Studio is a one-person indie studio run by Arun from Kerala, India. Arun is also an aerospace engineering researcher, and builds games on the side. The studio's games are gentle to play, work offline and need no account. First releases are Moonrope, a one-touch rope-swing game, and Felt Flight, a paper-plane game set in a stitched felt world.

Contact: arunvt.dev@gmail.com
