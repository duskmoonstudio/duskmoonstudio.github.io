# duskmoonstudio.github.io

Website of Dusk Moon Studio.

- `/` home page for **Moonrope** (one-touch rope-swing game) and **Felt Flight** (one-touch paper plane game)
- `/privacy-policy.html` Moonrope privacy policy
- `/felt-flight/` Felt Flight page, with its `privacy-policy.html` and `terms.html`
- `/app-ads.txt` AdMob authorised sellers, shared by all the studio's apps

Live at https://duskmoonstudio.github.io
